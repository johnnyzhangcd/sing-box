sing-box · GlobalProtect endpoint

纯 Go GlobalProtect 的完整架构

一个不接管宿主机路由、同时支持 TCP 与 UDP 的用户态实现：控制面负责认证、证书、HIP 与会话刷新；数据面把 GPST 帧接入 gVisor 网络栈，再作为 sing-box endpoint 提供标准拨号能力。

VM 实测通过 纯 Go TLS / GPST TCP + UDP 后台重连 HIP 初次 + 周期检查

一眼看懂

蓝色是控制面，绿色是实际业务流量，橙色是贯穿两者的生命周期。GlobalProtect 不创建系统 TUN，也不修改 VM 或宿主机默认路由。

控制与认证 业务数据 状态与生命周期

控制面：从 Portal 到可用隧道

1

目标解析与 Dial Fields

标准 sing-box dialer 负责 detour、绑定地址、路由标记与域名解析。域名 dialer 延迟到服务启动后创建，避免 DNS 初始化顺序问题。

2

Portal 认证

执行 prelogin 与 getconfig，选择匹配的 gateway。Portal 不存在时可回退到直连 gateway 流程。

3

逐目标 TLS 身份

Portal 与 gateway 各自使用实际目标主机名进行 SNI 和证书验证；用户显式配置 sni 时才固定覆盖。

4

网关登录与配置

获取 cookie、隧道 URL、分配地址与 MTU，构造不可变 session state 并交给数据面。

5

HIP 合规检查

先调用 hipreportcheck；服务器要求时生成与 MD5 关联的主机报告并提交 hipreport，失败则不冒充成功。

6

周期维护

按 Portal 下发的 HIP 间隔提前一分钟重检；认证刷新后使用最新 session。失败采用有上限的短周期重试。

数据面：标准 endpoint，可接 mixed 或系统 TUN

应用或系统 TUN 把流量交给 sing-box；GlobalProtect endpoint 在进程内部维护一套用户态网络栈。宿主机看到的唯一外部 VPN 连接是到网关的 TLS 会话。

1. InboundSOCKS / mixed 接收 TCP 与 UDP
2. Route按 tag 选择 GlobalProtect endpoint
3. gVisor在用户态创建 TCP/UDP socket
4. GPST添加 16-byte header 与 keepalive
5. Gateway经 TLS 隧道收发 IP packet
网络边界：mixed 测试仍只监听 VM 的 127.0.0.1；TUN 测试在专用 VM 上临时创建接口和策略路由，保留 LAN 管理网段，退出后确认接口、防火墙规则与 IPv4/IPv6 策略路由均已清理。

生命周期与恢复策略

两种启动模式

默认仍在 PostStart 后台连接，适合 SOCKS / mixed。启用 wait_for_ready 后在 Start 阶段等待首次隧道 ready，成功后才启动 TUN 等 inbound；永久错误直接终止启动，取消操作可立即唤醒。

首次连接失败

每次尝试受 reconnect_timeout 约束；瞬态错误从约 2 秒起指数退避并加入抖动，永久认证/证书错误会停止自动重试，避免账号锁定和请求风暴。

运行中断线

先尝试复用当前 session；若恢复失败，再重新认证并原子刷新地址与 MTU。启用 wait_for_ready 时，新拨号按调用方 context 等待重连；默认模式仍快速返回 not-ready，保持兼容。

周期 HIP

隧道就绪后独立计时；检查失败最多 1 分钟后重试，成功后恢复 Portal 指定周期。

Close

取消后台 context、等待循环退出、关闭 transport，再以独立超时执行 logout；重复调用安全。

构建与最小配置

GlobalProtect 与 gVisor 是显式构建特性。下面的 mixed 示例不会创建系统 TUN；系统 TUN 配置应在 endpoint 中增加 "wait_for_ready": true。平台标识会自动检测，macOS 在 Intel 与 Apple Silicon 上都会按协议要求报告为 mac-intel。

CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
  go build -tags "with_globalprotect,with_gvisor" \
  -o sing-box-globalprotect ./cmd/sing-box
{
  "endpoints": [{
    "type": "globalprotect",
    "tag": "gp",
    "server": "vpn.example.com",
    "server_port": 443,
    "username": "alice",
    "password": "<redacted>",
    "disable_dtls": true,
    "reconnect_timeout": "5m"
  }],
  "inbounds": [{
    "type": "mixed",
    "tag": "gp-local",
    "listen": "127.0.0.1",
    "listen_port": 2080
  }],
  "route": { "final": "gp" }
}
